# HERO's CUP 公式サイト

> 次は、きみだ！ — すべての子どもに「ヒーローになる瞬間」を届ける少年野球大会

`company-website` リポジトリ内の独立した静的サイトです。ビルド不要（HTML / CSS / Vanilla JS）。
公開URLは `https://pumps.haki-pro.com/heros-cup/`（GitHub Pages）。

## ページ構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | トップ。「みんながヒーローになれる」を主軸に、理念 → 4つの開催の軸 → 課題と価値 → 大会体験 → 代表メッセージ → 第1回大会バナー → 表彰 → CTA |
| `about.html` | 大会について。大会理念、開催の軸、なぜ今 HERO's CUP なのか、記憶に残る大会体験8項目、HERO審査制度、代表メッセージ |
| `rules.html` | **大会規約**（全10条）。理念／開催概要／基本競技ルール／特別ルール／試合前イベント／HERO審査制度／演出ルール／表彰／救護／参加チームへのお願い。サイドに追従目次 |
| `first.html` | **第1回大会 HERO's CUP in 三原**。開催概要、想定スケジュール（DAY1/DAY2タブ切替）、トーナメント構成、会場レイアウト（航空写真＋ピン）、表彰 |
| `entry.html` | 参加要項、エントリーの流れ、FAQ、実行体制・お問い合わせ |

スポンサーページは意図的に設けていません。

## 設計方針

- **第1回大会の情報は `first.html` に隔離**しています。三原市・古川製作所グランドでの開催は第1回に限った条件のため、
  トップ・about・rules 側は会場に依存しない書き方にしてあります。第2回以降は `second.html` 等を追加し、
  `first.html` はアーカイブとして残す想定です。
- 大会規約は条文構造（`.art` に `counter-increment`）で組んでいるため、条の追加・削除で番号は自動採番されます。
  ただし目次（`.rule-toc`）のリンクは手動更新が必要です。

## JavaScript（`assets/js/heros.js`）

- ヘッダーのスクロール状態切替（ヒーロー上は透過）
- モバイルドロワー開閉
- IntersectionObserver によるスクロール表示アニメーション（`.rv` / `data-delay`）
- スケジュールの DAY1 / DAY2 タブ切替（`[data-tabs]`）
- 現在ページのナビ強調

`prefers-reduced-motion: reduce` 環境ではアニメーションを無効化します。

## 画像素材（`assets/img/`）

ロゴは公式ロゴデータ、その他は大会資料PDFから抽出し、背景を透過処理したものです。

背景の白を落とす際は、単純なしきい値ではなく **画像の外周とつながっている白の領域のみ** を背景と判定しています。
しきい値だけで抜くと、ロゴ内部の白い文字（HERO'S）や白いリボンまで一緒に透明化されてしまうためです。
縁のJPEGにじみは部分アルファに変換し、白に対する合成を解いて色を復元しています（白フリンジ対策）。

- `heros-logo.png` … HERO's CUP 公式ロゴ（公式データより背景透過処理）
- `abe-tomohiro.png` … 代表・安部友裕（背景透過）
- `venue-aerial.jpg` … 古川製作所グランド航空写真（会場レイアウトの下地）
- `trophy.png` … HERO賞用トロフィー
- `logo-braveup.png` … brave up! Entertainment ロゴ
- `favicon.png` … ファビコン

## 更新時の注意

- 会場レイアウトのピンは `first.html` 内の `.vpin` に `left` / `top` をパーセント指定しています。写真を差し替える場合は座標の再調整が必要です。
- 想定スケジュールの時間枠はPDF記載の枠に基づく暫定版です。組み合わせ確定後は `first.html` の `.timeline` を更新してください。
- 参加費・締切・連絡先は `first.html` / `entry.html` / 各ページのフッターに記載があります。変更時は全ページを確認してください。
