# PowerPoint（.pptx）で作るとき

オーナーが「PowerPoint」を選んだ・.pptx を渡して「これで資料を作って」と言った場合（2026-10-31 に実施）。

## 作り方

1. 渡された .pptx は `markitdown` か python-pptx で文字とノートを全部読む（元のノートは台本の材料にする）
2. 確認は SKILL.md §2 と同じ（スタイル・用途・テーマ）。形式（PowerPoint / HTML）も同じ回答欄で聞く
3. `scripts/pptx_helpers.py` を使って python-pptx で組む
   - 16:9（1280×720 の px 指定）。色・文字の大きさはテーマ定義（`themes/`）に従う。部品の色トークンは選んだテーマに差し替える
   - 図はすべて PowerPoint の図形（線・円・多角形）で描く。画像にしない（オーナーが直せるように）
   - 書体は Windows・Mac 両方にある「游ゴシック」、数字は Arial
   - 日本語は語の途中で改行しやすいので、2行になる文は自分で改行位置を決める
4. **全スライドに発表者メモを入れる**（`workflows/speaker-notes.md`。必須）。`new_slide(note)` はメモが空だとエラーになる
5. `check_notes(prs)` を通してから保存
6. 見た目の確認：`soffice --headless --convert-to pdf` → `pdftoppm -png` で画像にし、全枚を自分で見て、はみ出し・重なり・語の途中の改行を直す（最大 2 周）
   - クラウドには游ゴシックが無いので似た書体で表示される。完了報告で「パソコンの PowerPoint で一度スライドショーして確認を」と伝える

## 渡し方

- ファイル名は前回と変える（例：`<題名>_登壇用.pptx`）。同じ名前だとオーナーの画面で古い方が開く（2026-10-31 に「20ページ無い」と指摘された）
- オーナーの作業フォルダ（`/home/user/shiryo/` など）に置いて送る
