# 発表者メモ（台本）— 必須

**オーナー指示（2026-10-31）：資料を作ったら、必ず全スライドに発表者メモを入れる。**
「オーナーが登壇しても、メモを見るだけで完璧に話せる」量と中身にする。省略・後回し・「必要なら追加します」は不可。

- PowerPoint（.pptx）：各スライドの「ノート」欄（スライドショーの発表者ツールで本人にだけ見える所）に入れる
- HTML スライド：同じ中身を `slides/<name>-notes.md` に書き、スライド番号ごとに見出しを付ける
- 元の資料にメモがあれば、言いたいことは残し、下の型に広げて書き直す

## 1 枚ごとの型（この順番・この見出しで書く）

```
【時間】3分（1枚目だけ「講演全体は約◯分＋質疑◯分」も書く）
【このページで伝えること】1行で
【台本】
そのまま声に出して読める話し言葉（です・ます）。
スライドの図のどこを見せるか（「グラフを見てください」「下の黒い帯」）も書く。
専門用語は 用語（やさしい言い換え） の形で、初めて出た所で説明する。
【会場への問いかけ】手を挙げてもらう質問・考えてもらう問い・その場で試す問題と、予想される反応（ある枚だけ）
【聞かれたら】出そうな質問 → 答え（ある枚だけ）
【注意】言ってはいけない言い方・断定しすぎな所（ある枚だけ）
【出典】研究者・年・雑誌（研究を使った枚だけ）
★補足：時間が足りないときに削ってよい部分
【つなぎ】次のスライドへの一言＋「▶ ここでクリックして、次のスライドへ。次のメモは【◯◯】から読む」（最後の枚は不要）
```

## 中身の決まり

1. **台本は全文**。箇条書きのメモで済ませない。オーナーが読み上げるだけで話が通じる文にする
2. **時間の合計**を持ち時間に合わせる。わからなければ「約55分＋質疑5分」などと置き、1枚目に「★から削って調整」と書く
3. **最後のスライドのメモ**には、よく出る質問と答え（5〜10個）と「答えられない質問が来たら『調べて後日お答えします』と言ってよい」を入れる
4. **根拠のない数字・断定を台本に入れない**。オーナーの実感・意見は「データではなく私の実感です」と前置きを台本に書く
5. 事実の確認が要る所（経歴・実績など）を台本に書いたら、完了報告で「この1文は合っているか確認してください」と伝える
6. 保護者・選手に向けた資料でも、個人情報（子どもの氏名など）はメモに書かない
7. **【つなぎ】で話を投げっぱなしにしない**（2026-10-31 オーナー指摘「質問させてくださいなのに、その後何も文章ないやん」）。
   「質問させてください」「ご存じでしょうか」など次につながる一言を書いたら、その質問・中身を【つなぎ】の中にも（）で書き、
   次のスライドのメモでは、それを【時間】【このページで伝えること】のすぐ後に置く。
   【つなぎ】の最後には必ず「▶ ここでクリックして、次のスライドへ。次のメモは【◯◯】から読む」と書く
8. 語尾・言い回しは humanizer の考え方で、大げさな言葉・決めゼリフの連発を避ける

## 検査（完了前に必ず）

- PowerPoint：`scripts/pptx_helpers.py` の `check_notes(prs)` を通す（全枚にメモがあり【時間】【このページで伝えること】【台本】【つなぎ】がそろっているか。最後の枚は【つなぎ】不要）。【つなぎ】に「▶ ここでクリック」の行があるかも見る
- HTML：`<name>-notes.md` にスライドと同じ枚数の見出しがあるか数える
- 完了報告に「全◯枚にメモを入れた・合計◯字・全体◯分」を書く
